# An empty bar shows recents and suggestions

**Problem.** A blank box teaches nothing.

**Therefore.** Empty: Recent (last 8 records and commands) then Suggested actions for the current view and selected row.

**Larger patterns.** [[one-bar]]

**Sources.** Obsidian switcher, Superhuman, Linear

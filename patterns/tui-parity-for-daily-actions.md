# Daily human actions have a TUI path

**Problem.** Features land in CLI and MCP only.

**Therefore.** Every CLI or MCP function a human does in daily use also exists as a palette action and, if frequent, a key. Automation, diagnostics, import and export, backup, DAV configuration and sync administration may stay CLI or palette only. The palette registry is the checklist.

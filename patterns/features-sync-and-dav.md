# Sync, DAV and integrations framework

Local-first device sync, the sync runner, inbox, source mapping and the hosted CardDAV server. Calendar sync is in [[features-calendar-archived]].

Moved from FEATURES.md on 2026-10-29. Every row keeps its ID and text. Update a row's State and Now in the same session you change the feature ([[keep-the-tracker-accurate]]). Column meanings and the row lifecycle are in [[feature-rules]].

**Follows patterns:** [[sync-contract]], [[sync-safe-data]], [[sync-maps-structure-to-flat-fields]], [[conflicts-keep-server-store-local]], [[local-first]], [[field-sources-are-ranked]], [[idempotent-by-uid]], [[import-is-a-snapshot-sync-is-a-relationship]]

**Research:** [[research-sync-standard]], [[research-sync-standardization]], [[research-sync-building-blocks]], [[research-sync-engines]], [[research-mesh-architectures]], [[research-local-first-stacks]]

**See also:** [[open-discrepancies]], [[index]]

Integrations are already listed one by one (E05 calendar, E06 email, E07 address book, E08 messages, C09/C10 imports), but nothing yet defines the shared parts. Build these first so each integration is a small adapter.

**Where the TUI views are (2026-10-29):** the Sync view is hidden by default on a new setup. Reach it from Settings ("Open Sync", "Inbox"), from the bar or from the Hidden group of the Views screen on `v` ([[views-screen]], [[settings-view]]). Its key is no longer 0 unless you show it.

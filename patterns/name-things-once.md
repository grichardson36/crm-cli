# Name things once

**Problem.** The same thing has different names in the TUI, CLI, docs and schema.

**Therefore.** Each object and verb has one plain singular name set in the object registry, used in labels, crm schema, help, MCP tools and docs.

**Larger patterns.** [[objects-first]], [[borrow-before-inventing]]

**Sources.** Ubiquitous language (domain-driven design)

# Surface gaps to the user before deciding

**Problem.** A question has no pattern, or the code breaks one. An agent decides alone and creates the next inconsistency.

**Therefore.** Stop. User [[decision-cascade]]. Research the conventional answer in our inspirations (Dex, Clay, HubSpot, Monica, Folk, Attio, Pipedrive, Obsidian, Pi, Motion, Calendly) and in software practice. Report to the user: the gap, two or three conventions with sources, and a recommendation. After the user decides, write the pattern here, log the research in DESIGN-PATTERNS.md and update [[open-discrepancies]].

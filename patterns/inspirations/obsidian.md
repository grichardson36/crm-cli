# Obsidian

**What it is.** Local-first notes app on plain files with a small core and a large plugin ecosystem. Command palette and Quick switcher are separate core plugins.

**Research state.** mined. See [[inspirations]].

**What we take.**
- Quick switcher: fuzzy, empty box shows recents, Enter on no match creates the note. [[standards/interface]] [[standards/interface]] [[standards/interface]]
- Command palette: recent commands first, pinned commands, fuzzy ranking. [[standards/interface]]
- Wikilinks and autocomplete link to notes that do not exist yet. [[standards/interface]] [[standards/product-model]]
- Small core plus local plugins. [[standards/interface]]
- The vault shape itself: this pattern language is atomic notes with wikilinks. [[standards/product-model]]

**What we leave.** Two separate boxes for actions and notes. We merged them (M01).

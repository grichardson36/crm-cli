# Merge, duplicates, archive and undo

Duplicate detection, merge with a log, archive, restore, purge and undo.

Moved from FEATURES.md on 2026-10-29. Every row keeps its ID and text. Update a row's State and Now in the same session you change the feature ([[keep-the-tracker-accurate]]). Column meanings and the row lifecycle are in [[feature-rules]].

**Follows patterns:** [[merge-repoints-links]], [[undo-redo-two-stacks]], [[undo-refuses-when-stale]], [[undo-appears-in-the-bar]], [[soft-delete-restorable]], [[delete-asks-yes-no]], [[toast-names-action-and-target]], [[bulk-actions-always]], [[hidden-not-removed-links]]

**See also:** [[open-discrepancies]], [[index]]

**Where the TUI views are (2026-10-29):** the Archived view is hidden by default on a new setup. Reach it from Settings ("Open Archived"), from the bar or from the Hidden group of the Views screen on `v` ([[views-screen]], [[settings-view]]). Its key is no longer 9: key 9 is Settings in the default arrangement. A `[modules]` table you already have keeps Archived where you put it.

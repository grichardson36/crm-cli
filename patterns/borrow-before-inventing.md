# Borrow a proven pattern before inventing one

**Problem.** Each agent invents a local answer to a design question and the program drifts.

**Therefore.** For every design question ask what the best existing software already does. Adopt the agreed convention if it makes semantic sense and is not cumbersome to type. Log the choice and its source in DESIGN-PATTERNS.md.

**Because.** Users bring muscle memory from other tools.

# Pattern-language migration

The legacy catalog and its repeated operating instructions were reduced to a small decision system.

- Core gates: 8
- Supporting patterns: 7
- Operating guides: core, feature rules and domains
- Domain references: link model, command bar, input grammar, keyboard feedback, interface conventions and deal vocabulary
- Feature trackers, research and records: evidence, not governing decisions

Removed notes were folded into the active gates before deletion. The schema proposal was replaced by the current app domain diagram and [[link-map]]. Git preserves history. Do not recreate a note merely to retain an old decision: use the supporting-pattern criteria in [[core]].

Core now combines the former decision flow with eight ordered gates and guidance for adding supporting patterns or core gates. The source-of-truth gate classifies every representation as canonical, derived or a boundary translation. Anything else is a discrepancy in [[open-discrepancies]].

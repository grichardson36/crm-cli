# Sigils name things, plain words name time

**Problem.** Symbols for dates collide with symbols for people.

**Therefore.** Use a sigil for a named thing (person, tag). Use plain English for time-like facts (date, recurrence, location, reminder, deadline). Two families, as in the market.

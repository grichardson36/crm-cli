# Show the key beside every action

**Problem.** Users never learn the fast path.

**Therefore.** Every action row in the bar shows its key right-aligned. Aliases show too: typing new note shows Add note (n).

**Larger patterns.** [[same-key-same-verb]], [[one-bar]]

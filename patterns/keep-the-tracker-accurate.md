# Keep the feature-area notes accurate in the same session

**Problem.** Other agents rely on the feature rows and they go stale.

**Therefore.** Whoever changes a feature updates its State and Now in the same session, in the `features-*` note that holds the row (find it from [[index]]). Write BRANCH plus the branch name while work is unmerged and MERGED once on main. Never reuse a row ID. Add a new row to the area note that fits, with the next free ID of its letter.

**Sources.** [[feature-rules]] rule 7. FEATURES.md was folded into the feature-area notes on 2026-10-29 and retired.

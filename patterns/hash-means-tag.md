# # means a tag

**Therefore.** #tag applies a tag, on tasks as well as people. In the bar # narrows the results to tags. A tag is also a result row when its name is typed without #, and a person who matched only through a tag says "tagged #tag" ([[bar-results-act-like-views]]).

**Because.** Universal across Todoist, TickTick, Slack, GitHub.
